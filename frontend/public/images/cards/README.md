# Card and Tavolo Reflection Illustrations

Generated with the built-in image generation tool and post-processed with edge-preserving alpha unmultiplication to ensure clean transparent backgrounds in both light and dark themes with zero white halos.

These illustrations are designed for student reflection cards and conceptual nodes on the Tavolo workspace in CounselorBot.
