# v2.0.2 — Correzioni desktop

- All'apertura di un profilo SQLite precedente, l'app mostra il motivo del blocco
  e il pulsante Esci, senza provocare il crash macOS. I file del profilo restano intatti.
- Nella panoramica della classe, il desktop propone l'abbinamento locale
  (`/unisciti#k=…`) al posto dell'invito web che richiede già una sessione.
- Versione 2.0.2 coerente in app, backend, frontend e manifest.

## Installazione

Scaricare il DMG Apple Silicon (ARM64) per Mac M1/M2/M3/M4, il DMG Intel per
Mac Intel, l'installer EXE per Windows x64 oppure il DEB per Linux x64.
Ogni installer è accompagnato dal checksum SHA-256.

L'aggiornamento è manuale: i pacchetti updater firmati non sono disponibili
senza la chiave di firma configurata nel repository.

## Profili precedenti

La migrazione automatica SQLite → PostgreSQL non è ancora disponibile. Per
continuare a usare un profilo SQLite serve il bundle precedente compatibile.
Se si sceglie di iniziare con dati nuovi, chiudere app e servizi e conservare
l'intera cartella del vecchio profilo in una copia separata prima del nuovo avvio,
come descritto nella [guida desktop](https://github.com/nugh75/counselorbot-sbs/blob/v2.0.2/docs/operations/desktop-teacher-guide.md#avvio-bloccato-dal-vecchio-profilo-sqlite).
Cambiare il numero in `layout.json` non converte il database.
