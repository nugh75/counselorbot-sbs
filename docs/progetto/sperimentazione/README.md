Cartella dedicata al diario della sperimentazione di CounselorBot: raccoglie in un
solo punto la cronologia delle attività di validazione e dei contatti di ricerca.
Il nome `sperimentazione` è scelto apposta per non confondersi con le altre
cartelle di `docs/progetto/` (documentazione stabile, organizzazione, comunicazioni).

## Contenuto

- [`diario-sperimentazione.md`](diario-sperimentazione.md) — cronologia bilingue
  (italiano + inglese) alimentata dalle fonti sotto elencate.
- [`istruzioni-agenti.md`](istruzioni-agenti.md) — istruzioni per gli agenti su
  come aggiornare il diario (formato voci, fonti, verifiche).

## Fonti del diario

- `../diario.md` — cronologia generale del progetto (base di partenza).
- `../comunicazioni/` — le 4 schede depurate (testi integrali nel repo privato
  `counselorbot-sbs-private`, stessi percorsi).
- `../../rebranding-compassbot-feedback-email.md` — bozza mail sul rebranding CompassBot.
- `../../presentazione-kth-eecs-2026-09-01.md`,
  `../../presentazione-kth-2026-09-09-it.md`,
  `../../presentation-kth-2026-09-09-en.md` — presentazioni al KTH.
- Git log e pull request recenti (`git log --oneline`, `gh pr list`) — attività di sviluppo.

## Regole brevi

- Ogni voce cita le fonti con link relativi verificabili.
- Mai segreti o credenziali nel diario (solo riferimenti ai documenti).
- Mai date inventate: se la data non è certa, scrivere "data dal commit" o "s.d.".

# Experimentation

Folder for the CounselorBot experimentation journal: a single place for the
chronology of validation work and research contacts. The name `sperimentazione`
is deliberately distinct from the other `docs/progetto/` folders (stable docs,
organisation, communications).

## Contents

- [`diario-sperimentazione.md`](diario-sperimentazione.md) — bilingual chronology
  (Italian + English) built from the sources listed below.
- [`istruzioni-agenti.md`](istruzioni-agenti.md) — instructions for agents on
  how to update the journal (entry format, sources, checks).

## Journal sources

- `../diario.md` — general project chronology (starting point).
- `../comunicazioni/` — the 4 redacted sheets (full texts in the private repo
  `counselorbot-sbs-private`, same paths).
- `../../rebranding-compassbot-feedback-email.md` — CompassBot rebranding email draft.
- `../../presentazione-kth-eecs-2026-09-01.md`,
  `../../presentazione-kth-2026-09-09-it.md`,
  `../../presentation-kth-2026-09-09-en.md` — KTH presentations.
- Recent git log and pull requests (`git log --oneline`, `gh pr list`) — development activity.

## Short rules

- Every entry cites its sources with verifiable relative links.
- No secrets or credentials in the journal (references to documents only).
- No invented dates: when the date is uncertain, write "date from commit" or "n.d.".
